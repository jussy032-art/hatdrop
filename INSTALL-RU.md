# Передача проекта на хостинг

В папке `hatdrop/` находится полный проект сайта и бота из исходного архива,
с обновлённым оформлением. Загружать нужно содержимое этой папки,
сохраняя структуру `static/`, `images/`, `img/`, `templates/`.

## Что обновлено

- Общая тема: более яркие золотые кнопки, медные рамки, тёмно-фиолетовые панели.
- Один пиксельный шрифт Monocraft для интерфейса, жирные надписи на кнопках.
- Меню из четырёх карточек: мины, лидеры, стейкинг, босс.
- Обновлённый рисунок босса и арена с воротами и фонарями.
- Локальные файлы шрифтов и их лицензия включены.

Серверные Python-файлы, зависимости и игровая механика не менялись.
Локальные страницы предпросмотра и тестовые данные в поставку не входят.

## Обновление действующего сервера

1. Сохраните резервную копию действующего проекта и базы данных.
2. Сохраните действующие переменные окружения, токены, настройки подключения
   к базе, файлы сессий и другие рабочие данные. Они не заменяются этой поставкой.
3. Остановите действующий процесс приложения перед заменой файлов.
4. Перенесите файлы из `hatdrop/` в существующую папку приложения,
   сохраняя серверные файлы данных и конфигурацию.
5. Запустите приложение прежним способом и проверьте логи.
6. Обновите страницу мини-приложения. Если Nginx/CDN кеширует HTML,
   очистите кеш HTML. Ссылки на новые стили имеют обновлённые версии.

Никакие действия на хостинге при подготовке этой папки не выполнялись.

## Запуск на новом Linux-хостинге

Рабочая папка — `hatdrop/`. Установите зависимости из `requirements.txt`
в виртуальное окружение. Настройте реальные переменные окружения
и постоянное хранилище данных, как в действующей установке.
Наличие рабочей базы и настроек необходимо для запуска игры и бота.

Пример команды запуска Flask-приложения за обратным прокси:

```sh
gunicorn --workers 1 --threads 4 --bind 127.0.0.1:8000 app:app
```

Один worker соответствует устройству исходного проекта: при загрузке
модуля запускаются фоновые обработчики. Несколько workers или несколько
параллельных экземпляров могут дублировать эти обработчики.
Не используйте `--preload`. Для Nginx сохраните действующие настройки
домена, TLS и проксирования; новый домен и сертификат в поставку не входят.

## Проверка

- Открыть меню, апгрейд, профиль и лавку на телефоне.
- Убедиться, что изображения и шрифты загружаются без 404.
- Проверить меню босса при активном и отсутствующем боссе.
- Проверить штатную работу Telegram-бота и действующей базы.

Проверено при сборке: все исходные Python-файлы сохранены побайтно;
синтаксис Python и изменённых JS-файлов проверен. Полный запуск с боевой
базой, токенами и интеграциями на локальном компьютере не выполнялся.
В `file-manifest.json` находятся список изменений и SHA-256 файлов проекта.
