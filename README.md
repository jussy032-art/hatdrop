# Hatdrop

Telegram-бот и игровое веб-приложение с пиксельным оформлением Nightfall.

Исходный проект находится в `hatdrop/`. Инструкция для установки:
[INSTALL-RU.md](INSTALL-RU.md).

Включены интерфейс, оформление босса, карта меню, локальные шрифты и графика.
Рабочие токены, переменные окружения и база данных в репозиторий не входят.
Используйте собственные настройки при установке.

Monocraft используется по лицензии SIL OFL; текст лицензии находится в
`hatdrop/static/fonts/Monocraft-LICENSE.txt`.
